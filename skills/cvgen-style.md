# cvgen-style

来源：品牌宣传、极简产品广告、三维动画短片、手绘结合实拍、歌词卡点。纸艺定格和纸拼贴只作为禁止项。H3 会把定格写成正面要求，成片发呆。

可用预设：品牌宣传、极简产品广告、三维动画短片、手绘结合实拍、歌词卡点。

禁止写成正面风格：纸艺、定格、拼贴、停格组装。需要这些质感时，只在 ban 里写“禁止定格和拼贴停顿”。

操作：

- `cvgen entity add Style '{"title":"品牌宣传","medium":"真人电影感","grade":"统一光线和调色","ban":"禁止定格、拼贴、仿造标识、字幕和水印"}'`
- `cvgen link styled_as <镜头> <风格>`
- 想从已有片子提取时，发 `cvgen style extract <成片>`，服务写回 Style。agent 再决定是否连到镜头。
