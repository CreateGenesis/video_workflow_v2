# cvgen-product-ad

来源：极简产品广告。三张锚定图和一个主动作决定产品是否认得出来。自动节拍识别会切错，已舍弃。配乐走 `cvgen music`。

先写一句叙事脊柱：发布、功能触感，或色彩家族。多款只留一个主推款，其他款晚一点进入。每个节拍只有一个主动作。

三张锚定图必须分开入库，不能拼成一张宫格：

- 主视角：轮廓和开场方向。
- 细节：材质、开合、按钮或屏幕。
- 结尾：产品和已确认文案的位置。没有真实标识时不补假标识。

开头必须尽快给出产品动作。空镜、镜面白底、假界面和粒子不能占时间。

操作：

- 已有照片用 `cvgen media upload <文件> --kind image --role 细节`。
- 没有照片时，确认生图已配置，再 `cvgen image <镜头> --role 细节`。连做三次，分别改镜头标题后再提交。
- `cvgen shot compose <镜头>` 后 `cvgen generate <镜头>`。
- 需要可控配乐时 `cvgen music <文案>`，再 `cvgen edit mix <剪辑>`。
